1. Введение
Задача сортировки больших наборов целых чисел является одной из фундаментальных задач в области обработки данных. При работе с большими объёмами данных последовательная сортировка может занимать много времени, а использование MPI технологий позволяет распределить данные и вычисления между несколькими процессами что в свою очередь должно поспособствовать ускорению выполнения задачи
    В данной работе реализованы две версии алгоритма сортировки:
Последовательная (SEQ) — обычная последовательная версия
Параллельная (MPI) — версия с распределением между несколькими процессами
Цель работы: реализовать параллельный алгоритм сортировки и сравнить его производительность в сравнении с последовательной версией

2. Постановка задачи
    Входные данные:
using InType = int;
    Выходные данные:
using OutType = int;
    Формат данных:
Элементы генерируются случайным образом с использованием равномерного распределения std::uniform_int_distribution в диапазоне [0, 1000]
Размер данных для тестов производительности: N = 15 000 000 элементов
    Ограничения:
Если N = 0 то сортировка не выполняется, используется поразрядная сортировка по основанию 10

3. Базовый алгоритм (последовательный)
1) Генерация данных: создание вектора случайных целых чисел
2) Поразрядная сортировка: определяется максимальный элемент, для каждого разряда: подсчёт количества элементов данного разряда, построение префиксной суммы, перемещение элементов в промежуточный массив с сохранением порядка, копирование результата обратно в исходный массив
3) Возврат количества отсортированных элементов
    Сложность:
Временная: O(k * N) k - колличество разрядов в максимальном числе

4. Схема параллелизации
1) Распределение данных: процесс 0 генеиирует исходный вектор, затем  данные распределяются между процессами с помощью MPI_Scatterv
2) Локальная сортировка: каждый процесс занимается выполнением поразрядной сортировки своей части данных
3) Объединение результатов: Используется алгоритм четно-нечётного слияния Бэтчера при котором на каждом шаге процессы объединяются в пары, затем один процесс отправляет данные, а другой принимает и выполняет слияние, шаг удваивается на каждой итерации
4) Сбор результатов: после завершения объединения процесс 0 содержит отсортированный массив, аоличество элементов рассылается всем процессам через MPI_Bcast
